## 4) Conversion Architecture Snapshot

- Homepage pathing is now exam-first: `/` -> `/celpip` or `/ielts`.
- Exam hubs use four equal skill cards (Listening/Reading/Writing/Speaking).
- Skill pages route to one primary service CTA per skill, then show free lesson links via `SkillFreeLessons`.
- Pre-payment pages (`/ai-feedback`, `/essay-correction`, `/tutoring`, `/webinar`) run in reduced/minimal header mode to lower distractions.
- Footer still provides non-conspicuous global navigation so users are not trapped.

## 5) Biggest Cognitive Overload Risks Remaining

1. Route duplication for AI feedback: both `/ai-feedback/` and `/celpip/writing/ai-feedback/` expose near-identical sales content.
2. Lessons volume dominates index size (308 of 381 URLs), which can bury core paid pages in crawl and user attention.
3. Webinar page currently includes a placeholder video section (`WEBINAR_VIDEO_EMBED_URL` empty), which adds an unfinished block near conversion intent.
4. Full header nav still contains many options on non-guided pages; this is fine for discovery, but can still create early-path branching from top-level content pages.

## 6) Funnel Clarity Strengths Now

- Human essay correction now defaults to direct Stripe checkout URL from `src/lib/offers.ts` (no mandatory Netlify env dependency).
- CELPIP writing path pushes users directly to `/ai-feedback` with a single dominant CTA.
- IELTS writing path pushes users directly to `/essay-correction#start-checkout` with explicit CTA labels.
- Skill pages include exam/skill-specific free lesson links + grammar/vocabulary/all-lessons fallback links.
- Trust modules are present on one-click-to-payment pages (`/tutoring`, `/essay-correction`, `/ai-feedback`, `/webinar`).
