# Lesson Layout Standard

Use this layout for all lesson writing and lesson regeneration.

## Page flow

1. Short, easy title
2. One introductory context paragraph
3. `Examples`
4. `Lesson Map`
5. `Core Lesson`
6. `Common Mistakes`
7. `Practice Lab`
8. `Why It Matters`
9. `Get Feedback`

## Section notes

### Context paragraph
- Explain the topic in plain English.
- Tell the learner what the topic does.
- Keep it short enough to read in one breath.
- Give the learner context before rules, labels, or long explanations.

### Examples
- Put examples near the top.
- Use real, relevant weak/strong contrasts.
- Do not reuse the same examples in practice.

### Lesson Map
- Must be clickable.
- Must link to the major sections.
- Should help scanning.
- Use it like a simple table of contents, not a decorative block.

### Core Lesson
- Explain the main idea simply.
- Use bullets and cards for clarity.
- Keep sentences short.
- Start each major section with a short intro line that tells the learner what they are about to read.

### Common Mistakes
- Show the errors students really make.
- Include the fix clearly.

### Practice Lab
- Only one interactive practice section.
- Immediate feedback is required.

### Why It Matters
- Explain the real value of the topic.
- Connect it to clear communication and exam performance.

## Style rules

- Write for a CLB 6 reader.
- Teach meaning first.
- Avoid vague textbook language.
- Use bold, italics, underlines, and emoji with purpose, not decoration only.
- When structure or wording is unclear, use Grammar Monster as the model for context-first teaching and section flow.
