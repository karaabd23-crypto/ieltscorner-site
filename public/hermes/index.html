Hermes Personal Assistant is Kara Abdolmaleki’s private assistant for research, task coordination and authorized account workflows. It is not a public sign-up service.

Why connect a Google account?

Google access is used only for the account owner’s requested assistant functions, within the permissions granted. These may include reading email, reviewing calendars, looking up contacts and working with authorized business documents. A specific calendar event or invitation may be created only when authorized and when the required permission has been granted.

Permission is not a blank cheque

Gmail access is read-only. Enabling a Google API in Cloud Console does not itself give this assistant access. Each connected service requires a separate supported authorization flow; not all services described here are currently connected.

Sending messages, deleting data, publishing content, changing account settings and spending money are not implicitly authorized by connecting an account.

Your information stays off this page

This public site describes the application. It contains no account dashboard, sign-in form, private messages, access tokens or account content. The assistant dashboard is separately protected.

Read the privacy policy for Google data use, storage, processors and revocation, or contact the application owner.
