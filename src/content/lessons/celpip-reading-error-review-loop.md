## Intro
Most CELPIP reading plateaus come from repeating the same mistakes. A clear review loop turns each mistake into a correction rule.

## Examiner Criteria
- Accuracy improves over repeated sets.
- Error types reduce because strategy changes are applied.
- Candidate demonstrates controlled reading decisions, not random retries.

## Mistakes
- Checking only final score, not reason for each error.
- Reviewing wrong answers without classifying the cause.
- Repeating the same practice type without targeted correction.

## Strategy
1. For each wrong answer, label one cause: distractor, inference, viewpoint, timing, or diagram.
2. Write one correction rule for that cause.
3. In the next practice set, track whether the same cause appears again.

## Example
Error: Chose an option with matching vocabulary but wrong meaning.
Cause: Distractor.
Correction rule: "I must find sentence-level proof before final selection."

## Exercise
1. Review ten wrong answers from recent sets.
2. Label the cause category for each error.
3. Write one correction rule per category and test it in your next timed session.
