## The simple idea

You do not need the word *accusative* for IELTS. You only need to know object forms like **me, him, her, us, them**.

Use object forms after verbs and prepositions. For example: *The teacher helped him.* / *This rule applies to them.*

<div class="lesson-grid">
  <div class="panel">
    <h3>Subject form</h3>
    <p>I, he, she, we, they</p>
  </div>
  <div class="panel">
    <h3>Object form</h3>
    <p>me, him, her, us, them</p>
  </div>
</div>

## Useful patterns

<PatternTable
  caption="Use object forms in these positions"
  rows={[
    { pattern: "verb + object pronoun", meaning: "after action verbs", example: "The policy affects them directly." },
    { pattern: "preposition + object pronoun", meaning: "after to/for/with/about", example: "This law is unfair to him." },
    { pattern: "between + object pronouns", meaning: "pair structure", example: "The decision was made between us." }
  ]}
/>

<details class="panel">
  <summary><strong>Quick check trick</strong></summary>
  <p>Remove the other person from the sentence. If you would say "me", not "I", use object form: "between you and me".</p>
</details>

## Common mistakes

<Callout type="warning" title="High-frequency errors">
- "between you and I" ❌  
- "This helps she" ❌  
- "The report focuses on they" ❌
</Callout>

## Practice

1) Fix: *This policy helps she and I.*  
2) Fix: *The report focuses on they.*  
3) Write one sentence with *between us*.
