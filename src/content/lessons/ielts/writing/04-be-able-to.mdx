## Why IELTS candidates should care

"Can" is fine — but overusing it makes your writing repetitive.  
"Be able to" lets you express **ability across time** more flexibly.

<PatternTable
  caption="Time forms (high-frequency for IELTS)"
  rows={[
    { pattern: "can", meaning: "general present ability", example: "People can access information instantly." },
    { pattern: "was/were able to", meaning: "managed to do something (often one-time success)", example: "After the reforms, low-income families were able to afford childcare." },
    { pattern: "have/has been able to", meaning: "ability achieved up to now", example: "Many countries have been able to reduce infant mortality." },
    { pattern: "will be able to", meaning: "future ability", example: "If schools invest in training, teachers will be able to personalize feedback." }
  ]}
/>

<Callout type="note" title="Nuance that boosts band score">
<strong>was able to</strong> often implies success in a specific situation (managed to).  
Compare:
- "He could swim" (general ability)
- "He was able to swim across the river" (he succeeded)
</Callout>

## Common IELTS mistakes

<Callout type="warning" title="Avoid these">
❌ "People are able to can…" (double modal)  
❌ "He was able to went…" (wrong verb form)  
✅ "He was able to go…" / "He could go…"
</Callout>

## Practice: upgrade "can" without changing meaning

Rewrite using "be able to" where it fits:

1) Online classes can help rural students.  
2) Governments can reduce emissions by taxing carbon.  
3) After the scholarship, she could study abroad. (make it "managed to")
