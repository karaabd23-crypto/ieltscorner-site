# 2026-10-07: SEO batch (www redirect, /sitemap.xml, canonical audit)

- `src/integrations/sitemap-xml.mjs` (new) + `astro.config.mjs`: build now writes a flat `/sitemap.xml` (merged from the `@astrojs/sitemap` chunks, same `SITEMAP_EXCLUDE` filter) with `<lastmod>` = build date. `sitemap-index.xml` and `sitemap-0.xml` still ship.
